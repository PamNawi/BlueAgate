# Where do I Start?
- The game industry is around of bouncing ideas off another person, so being a solo level developer can be quite difficult. 

- Keep in mind the goal of the level:
	- Consider to create an level around a core idea. This can be a mechanic or an narrative.
	- You need to know all the stuff that should be placed in a level like collectables and power.
	- Its important to consider the difficulty of the main player path
# Design Brief
This is a document should present relevant information for you to plan a level designer to plan. Should it contain:
- Discussions with team leads to guide
- Relevant constraints
- Features that should be presented
- Timeline / position in the game will be established 
- Storyline finalized - which key points and characters
- Different approaches for level designers and environment artists
