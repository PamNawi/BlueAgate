# User Story

As a Level Designer I want to be able to control where the player unlock new powers so that I can create power progression inside the game

As a Narrative Designer I want to be able to control when the player unlock new powers so that I can support with narrative when a new power is unlocked inside the game

As a player I want to unlock new powers as I progress inside the game

# Acceptance Criteria

- There's many places inside the narrative where the player will be unlocking new powers or even encountering new mechanics. The beat chart allows any member of the team to see where those events are planned inside the narrative and by consequence on the level.
- Its planned to have 2 places where new powers are unlocked nearby the entrance of the region after a dialogue with the operator:
	- Caverns should have the gravity pad
	- Temple of Mother should unlock after the direct connection with the operator is lost by malfunction. After the Temple of Mother, the player should be able to use the gravity pad as a spore carrier.
- Before the player reach this point inside the game, both powers should not be accessible for the player.
- The other blue stick-notes indicate only where the new mechanic that should be "always active" appears for the first time.

### Caverns small tutorial:
- The gravity pad needs to have a small introduction on how it should be used. The operator should say something about what are the command to thrown it. Maybe also it should say something after the player did the first jump correctly using this mechanic (a small trigger right above the platform after the first obligatory gravity pad jump on the caverns - very on the beginning of it)
